# 样式实验

实验只改变同一个广告位上的卡片样式，不改变广告身份，也不要让两组走不同的埋点事件名。

## 快速导航

- `experiment.md`: 分组号、样式变体，以及埋点里的实验号

`experiment.md` 指向 `../feed-card/card.md` 和 `../feed-card/exposure.md`。卡片和曝光规则也链回实验。

## 要点

- 用设备号或用户号做稳定分桶，刷新后仍落在同一分组。
- 分组号决定卡片样式，例如 control 用旧样式，variant 用新样式。
- 曝光和点击都带实验号、分组号。没有实验时这两个字段省略，不要填空字符串冒充。
- 样式变体可以换按钮颜色和布局，不能换掉广告标识。
