# 下单

对当前这辆购物车下单，按人类渠道计价，没有 95 折。人和网页改的是同一辆车，所以这里结算的就是页面上那辆车。

只说加入购物车、想看商品或询问价格时，禁止调用这个工具。

服务端只在本轮用户原文包含下面任一用语时才真正下单。历史对话里出现过这些用语，不能让这一轮的加购变成下单。
