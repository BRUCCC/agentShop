# 共用价格计算

> 草稿。规则以需求澄清之后的 `DECISIONS.md` 和 `SPEC.md` 为准。`技术方案.md` 还没通过之前，不要按这里实现。
> 启用时删掉 frontmatter 里的 `disable-model-invocation`。

## 何时使用

改价格、写价格测试、或检查网页和 agent 接口有没有各算一遍时使用。

## 规则

金额是整数新台币。门槛都看折前小计，折前小计等于单价乘数量。

1. 折前小计大于或等于 1000，商品金额减 100。
2. 渠道为 `agent` 时，把上一步的商品金额乘 0.95，四舍五入到整数元。`human` 不乘。
3. 折前小计大于或等于 990 时运费为 0，否则运费为 100。运费不参加减 100，也不参加 95 折。
4. 应付等于折扣后的商品金额加运费。

## 怎么做

1. 找到唯一的价格实现，不要新建第二份。
2. 按上面的定稿改它。
3. 用同一套测试覆盖网页订单和 agent 订单。
4. 规则变化时，同时改测试、`SPEC.md` 和本文件。

## 不要做

- 不要在页面组件里重算一遍。
- 不要在 agent 接口里重算一遍。
- 不要用商品数据里没写的价格。
