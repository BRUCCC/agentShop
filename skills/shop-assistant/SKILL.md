# 商店助理

这是给 agent 的入口，用来代替 MCP。调用同一组 JSON 接口，不另写价格。

## 何时使用

用户要在这个商店里查商品、改购物车或结账时使用。

## 怎么做

服务根地址是 `http://localhost:3000`。金额只相信接口返回值。购物车只有一辆，用浏览器 cookie 里的 `cart_id`。不要另建一辆给 agent。

具体动作看这些 skill：

1. `shop-recommend`：按需求推荐。少于 1000 件只取相关品类；达到 1000 件返回检索命中的一页。回复里不写商品 id，不贴评论。页内下单没有 95 折。
2. `shop-search`：搜索，默认 8 笔，最多 20 笔。
3. `shop-product`：按 id 看规格和库存。P001 和 P002 不能互换。
4. `shop-quote`：报价。不锁库存。
5. `shop-update-cart`：改这辆车。数量 0 是删除。不下单。
6. `shop-handoff`：锁库存 24 小时并给出确认链接。不下单。
7. `shop-place-order`：只有用户明确要下单时才下单。

页面上的 `POST /api/carts` 使用 `{ "channel": "human" }`，只是在还没有车时创建这一辆。对话栏改的是 cookie 里的同一辆。

对话栏顶部由用户提供 API key。模型地址和模型名称默认填在输入框里，请求时一并提交。不要把密钥写进仓库或回复。

## 不要做

- 不要建 MCP。
- 不要把「加入购物车」当成下单。
- 不要自己编价格、库存或评论。
- 不要一次取回全部商品。
