# 實作題：讓 AI agent 也能來逛的商店

来源：[Sr. Frontend Engineer Home Quiz](https://shepherdtech.notion.site/Sr-Frontend-Engineer-Home-Quiz-2a9a4b7afc888042ac89dd891ab6228a)

以下为页面中与作业方式、缴交物、面试相关的原文，未改写。产品需求见 `产品相关/产品需求.md`。

## 作業說明

以下是 PM 寫的需求初稿。就像真實工作一樣，這份需求不一定完美，可能有沒講清楚、互相矛盾，或你覺得不合理的地方。請用你的判斷完成這個專案。你可以調整、刪減或反對任何需求，但請把決策和理由記錄下來。

過程中不開放提問。遇到不清楚的地方，請自行做合理的假設，並記錄在 DECISIONS.md，面試時我們會一起討論。

- 不需要串接真實金流，結帳用模擬的即可。
- 建議投入 2 個工作天。
- 工具不限（Claude Code、Cursor、Codex、Copilot 等都可以），也不需要安裝任何特定的 skill 套件。我們想看的是你為什麼這樣設計你和 AI 的協作方式，而不是用了多少套件。
- 本題僅用於面試評估，作品不會用於任何商業用途。

## 繳交內容

請提供一個 GitHub repo（公開，或邀請我們加入），內容包含：

1. 可運作的產品：包含給人用的網頁，以及給 AI agent 用的結構化介面。介面形式自選，例如 MCP server、WebMCP 或有文件的 API。請在 README 寫下啟動與測試的方式。
2. DECISIONS.md：針對你調整過或有疑問的每一條需求，寫下原本的需求、你的假設、你的判斷、你做的取捨，以及你會怎麼回覆 PM。
3. AI 協作的過程：
   - 給 agent 讀的 context 檔（例如 AGENTS.md、CLAUDE.md 或 Cursor rules），以及實作前寫的 spec、plan、tasks。
   - 至少一個你自己寫的 skill，並說明它用了幾次、改過幾版。
   - 在 GitHub Actions 上跑的測試。價格計算只能有一份實作，網頁和 agent 介面共用。
   - 一段真實 AI agent（Claude、ChatGPT、Gemini 等皆可）在你的商店購物的紀錄，可以是對話紀錄或錄影。
   - 完整的 commit 歷史，請不要 squash。
   - AI_NOTES.md：記錄 3–5 個關鍵時刻，例如 agent 做錯而你抓到的地方、你決定不交給 agent 的部分、你因為某次失敗而調整 context 或 skill 的經過。

## 面試時的分享（約 60 分鐘）

面試會包含產品 demo、討論你的決策、導覽你的 AI 協作過程，以及現場用你自己的協作流程加一個小功能。請事先準備好開發環境，並能分享螢幕。

## 題目限制

以上題目請勿傳播或外流，以免影響其他面試者答題，謝謝體諒。若有困難或是不清楚的地方，請務必事先讓我們知道。
